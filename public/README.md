# public/

Static assets copied verbatim into the build.

`.nojekyll` is load-bearing for the GitHub Pages deployment: without it Pages
runs the output through Jekyll, which ignores every directory whose name starts
with an underscore — including `_next/`, where the entire JavaScript and CSS
bundle lives. The failure is silent and total: the HTML renders, every asset
404s, and nothing in the build log says why.

`trip-index.json` is generated by `npm run build:index` and is not committed.
